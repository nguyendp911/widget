# ViePN Lịch Việt

Ứng dụng SwiftUI iOS 17+, bản 4.0.0 (32). Bundle ID: `com.viepn.widgetplus`. Không có Widget Extension trong bản ký cá nhân.

**Trạng thái nhập dự án:** mã nguồn Swift và cấu hình Xcode đã được đưa lên. 375 asset V5 chưa được truyền từ gói dự án; cần bổ sung `Resources/Assets.xcassets` trước khi build IPA. Không sử dụng bản này để cài đặt.

Kiểm thử lõi: `bash Scripts/test-core.sh`.
