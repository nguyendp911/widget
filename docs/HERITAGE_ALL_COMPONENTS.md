# ViePN Heritage UI — component mapping

Derived from the user-supplied 1448 × 1086 px calendar heritage asset sheet, no synthetic replacements.

- 3 title ribbons → lunar day heading, family events section, traditional culture section.
- 10 function icons → launch day view, reminders, family events, preferences, culture, search, navigation.
- 10 festival pictograms → named traditional holiday rows in Culture section.
- 6 navigation buttons → previous/next week/month/year and add family event.
- 4 patterned tiles → selectable in-app decoration palette.
- Existing 6 full card backgrounds + 4 status badges + 7 ornaments stay intact.

Cropped PNG assets have soft transparent edges. Their imagery is static; descriptions and dates must remain dynamic SwiftUI text. Badge images from the reference sheet with embedded text are only shown on matching real events. PNG composites should not be repurposed to convey untrue festival dates.
